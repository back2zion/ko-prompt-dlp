# 인증 준비 체크리스트 (GS인증 / ISMS-P / CC / 조달)

> 인증은 **공인 시험·심사기관과 조직**이 수행한다. 아래는 제품 측 준비물이며, 획득을 보장하지 않는다.

## GS인증 (SW 품질, TTA 등)
- [ ] 기능/성능/사용성/보안성 시험 항목 정의, 매뉴얼·설치가이드
- [ ] 테스트 커버리지·결함 관리 기록(현재 자동화 테스트 63건 + SAST)
- [ ] 신뢰성(부하·장애복구) 시험 — **부하시험 미실시, 수행 필요**

## ISMS-P (KISA)
- [ ] 관리체계(정책·위험평가·내부감사) — 조직 영역
- [ ] 기술적 보호: 접근통제·암호화·로그(→ `compliance.py` 증적 리포트 활용)
- [ ] 개인정보 처리단계별 보호(마스킹·최소수집) 증적

## CC (공통평가기준, 공공 납품 시)
- [ ] 보안목표(ST)·보호프로파일(PP) 작성
- [ ] 위협모델(→ `THREAT_MODEL.md`)·보안기능요구(SFR) 매핑
- [ ] 평가용 형상·가이드 문서

## 조달 등록 (나라장터/디지털서비스)
- [ ] 사업자·직접생산확인, 가격·규격, 유지보수 체계

## 제품이 이미 제공하는 증적
- 접근통제(RBAC/OIDC), 암호화(KMS 봉투), 감사(해시체인), 정책 이력,
  컴플라이언스 리포트(ISMS-P/ISO 매핑, 서명), SAST/의존성 스캔 결과.

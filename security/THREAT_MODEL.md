# AX필터 위협 모델 (STRIDE)

범위: 검사 API, 이그레스 게이트웨이, 저장소, 브라우저 확장, 투명 프록시.

## 자산
- 프롬프트 원문(최고 민감), 검출 메타데이터, 정책, 감사로그, API/데이터 키.

## 신뢰 경계
사용자 단말 → (확장/프록시) → 게이트웨이/API → 저장소(DB) / KMS / 업스트림 LLM / SIEM.

## STRIDE
| 위협 | 시나리오 | 완화 (구현/상태) |
|---|---|---|
| **S**poofing | API 무단 호출 | API 키(상수시간 비교) + OIDC 베어러(JWKS·iss/aud/exp); 무차별 대입 잠금 |
| **T**ampering | 감사로그·정책 위·변조 | 감사 해시체인 검증, 정책 변경 이력(해시), 리포트 HMAC 서명 |
| **R**epudiation | 원문 열람 부인 | 원문 열람·정책변경·리포트export 감사 기록(행위자=OIDC subject) |
| **I**nfo disclosure | 원문 유출 | AES-256-GCM + 봉투암호화(KMS), 로그·SIEM엔 메타데이터만, 응답에 원문값 미포함 |
| **D**oS | 대량 요청 | (부분) 인증 잠금; **레이트리밋·쿼터 미구현** → 게이트웨이 앞단 WAF/게이트 권장 |
| **E**oP | 권한 상승 | 역할 랭크 검사(agent<viewer<admin), 최소권한 KMS IAM |

## 잔여 위험 (미완화 — 운영 전 처리)
- 레이트리밋/쿼터, 멀티테넌시 격리, 키 분리(리포트 서명키=데이터키 재사용 → 전용키 권장)
- 투명 프록시 TLS 가로채기의 법·정책 검토, 단말 CA 배포 보안
- 공급망: 의존성 고정·서명(현재 pip-audit로 axfilter 의존성 무취약 확인)
